五、注意事项

  1. 不要为了短而短：如果表达式里嵌套了三层 if 和两个 for，老老实实写循环更清楚；
  2. 推导式会一次性把结果生成到内存，数据量很大时考虑生成器表达式 (x for x in ...)；
  3. 字典推导式里的键必须是不可变类型。
