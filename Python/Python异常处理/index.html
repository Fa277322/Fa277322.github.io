异常 触发场景
ZeroDivisionError 除数为 0
TypeError 类型不匹配
NameError 变量名不存在
IndexError 列表下标越界
KeyError 字典键不存在
ValueError 值不合法，比如 int("abc")
ModuleNotFoundError 导入的模块不存在
SyntaxError 语法错误
KeyboardInterrupt 用户按 Ctrl+C

三、完整的 try 结构

四个块的执行顺序：

  1. try 里的代码正常跑完 → 执行 else；
  2. try 里抛异常 → 跳到对应的 except；
  3. 不管有没有异常，最后都执行 finally（常用于关闭文件、释放连接）。

自定义异常的好处是调用方可以精确捕获某一个业务异常，而不是笼统地 except Exception。

七、实践建议

  1. 不要吞异常：except: pass 会让问题被隐藏，排查起来非常痛苦；
  2. 捕获尽量具体，优先捕获能预料到的那几种；
  3. finally 适合放清理逻辑，文件操作更应该直接用 with。
