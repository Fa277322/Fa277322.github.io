六、后续组件

Keystone 跑通之后，按官方文档顺序继续：

组件 作用
Glance 镜像服务
Nova 计算服务（控制器 + 计算节点）
Neutron 网络服务
Placement 资源调度
Horizon Web 控制台
Cinder 块存储
Swift 对象存储

每个组件的安装套路都是：创建数据库 → 创建用户和授权 → 安装软件包 → 改配置文件 → 同步数据库 → 启动服务 → 验证。

七、踩坑记录

  1. 数据库装在 1511 版本会失败：换成 1908 及以上版本的 CentOS；
  2. yum 装 openstack 包报 404：阿里云源里 train 版本路径变了，按上面 baseurl 的方式手动补；
  3. keystone 返回 500：多半是数据库连接串写错，或者 db_sync 没执行；
  4. Apache 起不来：ServerName 没配置，会报 Could not reliably determine the server's fully qualified domain name。
