KVM 虚拟化技术：原理与实验

Fa2026-11-252026-11-25

一、虚拟化技术概述

1、虚拟化的几种实现方式

纯软件仿真：通过软件模拟完整的硬件环境。

  • 优点：可以模拟多种 CPU 架构；
  • 缺点：效率低。

虚拟化层翻译：在 host 和 guest OS 之间加一层 hypervisor。

方式 原理 特点
无硬件辅助的全虚拟化 hypervisor 运行在 ring 0，虚拟一个 CPU 给 guest OS，guest OS 不知道自己处于虚拟化环境 产生异常 → 捕获 → 翻译，效率低
半虚拟化 修改 guest OS 内核，让它知道自己运行在虚拟化环境中 性能提高，但支持的操作系统有限
有硬件辅助的全虚拟化 CPU 提供虚拟化支持（Intel VT / AMD-V） 不需修改内核，没有大量异常翻译过程

容器技术：轻量级虚拟化，没有 hypervisor，也没有独立的 guest OS。

2、KVM 是什么

KVM（Kernel-based Virtual Machine）是有硬件辅助的全虚拟化解决方案：

  • 依赖 Intel VT 或 AMD-V 支持；
  • 是一个可加载的内核模块，根据 CPU 类型加载 kvm-intel 或 kvm-amd；
  • 不需要修改操作系统内核，开源；
  • 从 Linux 2.6 起并入内核主线。

3、体系结构

组件 所在空间 负责什么
KVM 内核空间 CPU、内存、中断控制
QEMU 用户空间 网卡、显卡、磁盘等设备模拟
libvirt —— 通用虚拟化管理工具，含 API、守护进程 libvirtd、工具 virt-manager / virsh

二、实验环境搭建

1、硬件要求

  • CPU 必须支持虚拟化（一般默认开启，可在 BIOS 中确认）；
  • 如果是嵌套实验（VMware 里跑 KVM），要在虚拟机设置里勾选 Intel VT-x / AMD-V。

2、安装 CentOS 7

关键步骤：

  1. 创建虚拟机：CentOS 7 64 位，2 核 2G，NAT 网络，80G 单文件磁盘；
  2. 编辑虚拟机设置，勾选虚拟化支持，删除声卡、打印机；
  3. 安装时选择 virtualization host（虚拟化主机）+ virtualization platform（虚拟化平台）；
  4. 分区用 LVM，调大 /，调小 /home；
  5. 关闭 kdump。

七、常见问题

  1. lsmod | grep kvm 没有输出：说明模块没加载，先确认 CPU 虚拟化支持并检查 BIOS；
  2. **虚拟机启动报 KVM: no hardware support**：嵌套实验时 VMware 里没勾选虚拟化；
  3. 桥接后宿主机断网：检查 ifcfg-br0 和物理网卡配置是否配对，物理网卡不能有 IP；
  4. virt-manager 连不上：确认 libvirtd 服务已启动，防火墙放行。
