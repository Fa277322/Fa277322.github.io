这波常驻 Agent 是怎么回事

海外六家 Grok Bot、Dots、Claude Duet、Hermes、Muse、OpenClaw（龙虾），独立公司 Hark 的 Hark Pro，加上国产五家小豆、千问 Go、百度搭子、阿里灵光、腾讯 LightVela——本质是同一件事：关掉手机也能继续干活、会主动找你汇报的常驻 Agent。

分水岭还是那条：

  • 托管派（9 家）：把电脑、模型和安全交给厂商，拼的是谁的生态离你的钱和生活最近；
  • 本地派（3 家）：把 Agent 放在你自己的机器上跑，控制权归你，活也归你干。

四个最容易搞混的先说清：小豆和百度搭子是两个产品——小豆是字节 11 月 24 日刚公测的云端个人助理，百度搭子是百度智能云 3 月出的桌面办公 Agent；Hark 和 LightVela 也是两个产品——Hark Pro 是海外独立公司的电脑操作助理，LightVela 是腾讯轻量云的托管服务，里面跑的是开源 Hermes。

产品 厂商 / 出身 运行方式 价格门槛 核心卖点 最大代价
Grok Bot xAI 独立云端电脑 $30/月起 团队协作、X 实时信息、多 Bot 分工 无模型选择权，系统决定用哪个模型

Muse Meta Secure VM 云端电脑 免费 / $20 / $100 个人生活 + 工作长期跟进、WhatsApp 原生 连接器生态还在追赶

Hermes Nous Research · 开源 自己的服务器，本地优先 免费（自付算力） 闭环学习，自己写 Skill 越用越强 模型、算力、连接器全部自己搭

千问 Go！ 阿里 · 通义千问 千问 App 内，云端执行 内测中，未公布 会跟客服交涉办事：理赔、价保真办成 还在内测，跨平台覆盖未完全公开
百度搭子 百度智能云（DuMate） 你的桌面本地运行 免费 / Pro ¥59起 看得见屏幕，直接操作 Office 和本地文件 只做桌面办公，没有云端常驻和生活服务
阿里灵光 蚂蚁集团 · 阿里系 独立云主机持续运行 免费（未公布付费档） 闪应用造工具 + 2.0 长期事务托管 交易执行主要在支付宝生态内
腾讯 LightVela 腾讯轻量云团队 腾讯云托管开源 Hermes 免费试用起 把 Hermes 装进微信，7×24 免运维 本质是托管外壳，能力上限看 Hermes 和所选模型

怎么选：一句话收尾

要工作流托管，选 Dots 或 Grok Bot；要谨慎和判断力，等 Duet；要自己掌控一切，选 OpenClaw（广度）或 Hermes（深度）；在国内要办事，选 千问 Go！（交涉办事，还在内测）、小豆（生活跟进，刚公测）、LightVela（微信里的 Hermes 托管）；桌面办公自动化选百度搭子；要现场造工具兼长期管事，选灵光；最在意隐私又想开箱即用，看 Hark Pro；要一个长期跟着你生活和工作、每天主动汇报的个人 Agent，就是 Muse 这条路。

时间线：谁先谁后

  • 2025-11 阿里灵光首发（蚂蚁，一句话生成闪应用）
  • 2025-11-25 OpenClaw 以 Clawdbot 之名开源，常驻 Agent 的起点
  • 2026-02 Hermes Agent 开源，自托管框架，主打闭环学习
  • 2026-03 百度搭子 DuMate：桌面 Agent，本地沙箱跑办公自动化
  • 2026-04 LightVela 上线：腾讯轻量云托管 Hermes，接进微信；8-18 公测
  • 2026-08-11 Grok Bot 测试（xAI，11-02 出 1.0 转向团队协作）
  • 2026-09-08 Muse 推出（Meta，主打个人长期跟进）
  • 2026-09-29 Dots 发布（OpenAI DevDay，定位长期负责）
  • 2026-10-06 Hark Pro 发布（Brett Adcock，主打隐私）
  • 2026-10-13 千问 Go！亮相（千问 App 内开放申请）
  • 2026-10-21 Claude Duet 预览（Anthropic，仅美国排队）
  • 2026-10-27 灵光 2.0（蚂蚁升级成 Personal Agent）
  • 2026-11-24 小豆公测（字节豆包团队压轴入场）
